# Treatise-on-Cold-Damage-Diseases
## Computational Analysis of Formula Compatibility and Symptom Patterns in *Treatise on Cold Damage Diseases* (伤寒论)

A fully scripted, null-model-disciplined corpus analysis of 16 historical editions of *Shanghan Lun* / *Shanghan Zabing Lun* (280–1998 CE): dictionary-anchored formula extraction, passage-block co-occurrence networks, symptom–formula association rules, context-retrieval baselines, 加减法 (modification-rule) mining, and dose-stability analysis — with every headline claim tested against explicit null models.
